## 数据格式

所有词典使用统一的 `.dat` 二进制格式：

- **Header**: 32 字节（包含 contentStart 偏移量）
- **Entries**: 关键词-定义对
  - 关键词长度（4 字节，little-endian）
  - 关键词内容（UTF-16LE 编码）
  - 定义长度（4 字节，little-endian）
  - 定义内容（UTF-16LE 编码）
